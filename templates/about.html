About

Invoice CSV Studio turns invoice PDFs into structured CSV files. It combines PDF text parsing, OCR for scanned pages, and OpenCV-based layout checks so different vendor formats still produce usable tables.

Extraction runs in stages: text-layer parsing first (for PDFs with selectable text), then vision-based region detection, then advanced and general fallbacks. The first stage that returns a usable table wins.

System tools

  • Python 3.11+
  • Tesseract OCR
  • Poppler (for PDF → image conversion)
